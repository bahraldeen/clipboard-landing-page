### What I learned

Working on this landing page helped me practice structuring a full multi-section layout using both **Flexbox** and **CSS Grid**. I also reinforced my understanding of using CSS custom properties for consistent color theming and managing responsive layouts across desktop and mobile viewports.

```css
:root {
  --ios_color: hsl(171, 66%, 44%);
  --mac_color: hsl(233, 100%, 69%);
  --hedding_color: hsl(210, 10%, 33%);
  --pragraph_color: hsl(201, 11%, 66%);
}
```

### Continued development

In future projects, I want to focus more on:
- Adopting a **Mobile-First** CSS workflow.
- Refining fluid responsiveness across tablet breakpoints without relying on fixed widths.
- Improving accessibility (ARIA attributes and descriptive `alt` texts for all images).
